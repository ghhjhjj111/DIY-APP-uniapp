# DIY同城门户分类信息发布求职招聘房产汽车二手交易转让门户APP/小程序uniapp

源码地址：ym7k.com/19279/

这套 SYBMENHU 同城信息门户系统基于 Uniapp 开发，一套代码可以打包微信小程序、H5、安卓 / 苹果 APP，是仿 58 同城模式的本地便民分类信息平台，支持后台可视化 DIY 首页布局、自定义导航按钮，适合搭建县城、地级市本地同城门户。

### 前端板块

底部导航：首页、头条、发布、商家、我的。

- **首页**：顶部城市定位 + 搜索，Banner 广告位，后台自定义快捷分类入口（餐饮美食、休闲娱乐、汽车服务、婚庆摄影、家居建材、母婴专区等），推荐好店展示，支持自定义公告、一键发布引导模块，所有模块后台可视化配置，不用改代码。
- **商家页面**：商家分类导航、入驻店铺展示，商家广告引流，可做本地商家黄页、团购、店铺展示。
- **招聘板块**：完整招聘列表，可按城市、职位、薪资筛选；发布岗位表单齐全，职位类别、薪资区间、福利、学历、工作经验、工作地址、岗位描述，岗位支持标注五险一金、双休、房补等标签，求职者直接在线联系。
- **房产出租板块**：独立租房发布表单，住宅 / 商铺切换，户型、面积、租金、朝向、装修、楼层、房屋配置，满足租房、售房信息发布。
- **个人中心**：会员体系，我的招聘、我的简历、我的房产、车辆交易、物品交易、农林牧渔、生意转让、顺风车、本地推广、收藏、商家中心；配套开通会员、个人主页、客服、帮助中心等入口。

### 核心分类大全

求职招聘、房产租售、车辆交易、二手物品、生意转让、农林牧渔、顺风车、本地商家黄页、生活服务，覆盖同城绝大多数便民需求。

### 核心亮点

✅ Uniapp 跨端，小程序 / H5 / APP 多端打包
✅ **后台 DIY 可视化首页**，自定义图标、文字、模块顺序，灵活改版
✅ 独立招聘、房产、二手车、二手物品多表单，每个类目独立字段
✅ 商家入驻体系，店铺展示、商家分类、商家广告
✅ 会员付费体系，本地推广置顶、付费曝光变现
✅ 信息浏览统计，发布记录管理，内容后台审核
✅ 城市定位筛选，按地区检索信息
✅ 表单校验，违规信息提示，规避敏感联系方式直接发布

### 盈利方式

商家入驻费、帖子置顶推广、会员套餐、首页广告、分类广告、本地商家竞价排名。

### 适用场景

县城同城便民平台、本地招工租房门户、乡镇二手交易平台、本地生活黄页、行业垂直分类信息站。
